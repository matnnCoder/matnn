# 第1章：简介与入门

## 1.1 什么是 Matnn

Matnn 是一个轻量级的脚本编程语言，语法简单，同时提供了丰富的内置库和扩展能力。

### 主要特性

- **简洁的语法**：类似 JavaScript 的语法，学习曲线平缓
- **数学计算能力**：内置 Math 对象、Tensor 张量运算、3D 数学库
- **异步编程**：支持 Task 异步任务调度
- **面向对象**：完整的类和继承系统
- **模块化设计**：支持 import/export 模块系统
- **丰富的内置库**：HTTP、文件系统、加密、正则表达式等
- **跨平台**：支持 Windows、Linux、macOS

## 1.2 安装与运行

### 环境要求

Matnn 需要在支持的操作系统上运行，目前提供了 Windows 平台的编译版本。

### 获取 Matnn

Matnn 的编译产物位于 `matnn_example/matnn/` 目录下：

- `matnn.exe`：主程序入口
- `matnn.dll`：核心运行时库
- `*.dll`：各功能模块库

### 运行 Matnn 脚本

创建一个名为 `hello.mt` 的文件：

```matnn
Console.log("Hello, World!");
Console.log("欢迎使用 Matnn 编程语言");
```

使用命令行运行：

```bash
matnn.exe -run hello.mt//绝对路径或相对路径
```

### VSCode 插件

Matnn 提供了 VSCode 插件支持语法高亮和代码补全，插件位于 `matnn_example/vscode_plugin/` 目录下。

## 1.3 第一个 Matnn 程序

```matnn
Console.log("Hello, World!");
Console.log("欢迎使用 Matnn 编程语言");
Console.log("Matnn - 一个轻量级的脚本语言");
```

**输出结果**：

```
Hello, World!
欢迎使用 Matnn 编程语言
Matnn - 一个轻量级的脚本语言
```

### 代码解析

- `Console.log()`：输出信息到控制台
- 字符串用双引号 `"` 包裹
- 每行代码以分号 `;` 结尾

## 1.4 Matnn 脚本文件

Matnn 脚本文件使用 `.mt` 扩展名，这是 Matnn 的标准文件格式。

### 文件结构

一个典型的 Matnn 脚本包含：

1. **注释**：使用 `//` 表示单行注释
2. **变量声明**：使用 `var` 或 `let` 关键字
3. **语句**：执行特定操作的代码行
4. **函数**：可重用的代码块
5. **类**：面向对象的定义

### 注释示例

```matnn
// 这是单行注释

/* 
这是多行注释
可以跨越多行
*/
```
