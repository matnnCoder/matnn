# 第2章：变量与数据类型

## 2.1 变量声明

Matnn 使用 `var` 或 `let` 关键字声明变量。`let` 是 `var` 的别名，两者功能相同。

```matnn
var name = "Matnn";
var version = 1.0;
var isActive = true;

let age = 30;
let city = "Beijing";
```

### 变量命名规则

- 变量名可以包含字母、数字、下划线 `_` 和美元符号 `$`
- 变量名不能以数字开头
- 变量名区分大小写
- 不能使用 Matnn 的保留关键字

### 变量赋值

```matnn
var x = 10;
var y = 20;
var z = x + y;
Console.log("x + y =", z);
```

**输出结果**：

```
x + y = 30
```

## 2.2 数据类型概述

Matnn 支持以下基本数据类型：

| 类型 | 描述 | 示例 |
|------|------|------|
| number | 数字（整数或浮点数） | 42, 3.14 |
| string | 字符串 | "Hello" |
| boolean | 布尔值 | true, false |
| null | 空值 | null |
| array | 数组 | [1, 2, 3] |
| object | 对象 | {name: "Alice"} |
| function | 函数 | function() {} |

## 2.3 数字类型 (number)

Matnn 的数字类型既支持整数也支持浮点数。

```matnn
var intValue = 42;
var floatValue = 3.14;

Console.log("整数:", intValue);
Console.log("浮点数:", floatValue);
```

### 数字常量

Matnn 支持以下数字表示方式：

```matnn
var decimal = 10;
var hexadecimal = 0xFF;
var scientific = 1.2e3;
```

## 2.4 字符串类型 (string)

字符串使用双引号 `"` 或反引号 `` ` `` 包裹。

```matnn
var stringValue = "Hello";
var multiLine = `这是第一行
这是第二行
这是第三行`;
```

### 字符串拼接

使用 `+` 运算符拼接字符串：

```matnn
var greeting = "Hello";
var name = "Matnn";
var message = greeting + ", " + name + "!";
Console.log("字符串拼接:", message);
```

**输出结果**：

```
字符串拼接: Hello, Matnn!
```

## 2.5 布尔类型 (boolean)

布尔值只有两个可能的值：`true` 和 `false`。

```matnn
var boolValue = true;
var isGreater = 10 > 5;
Console.log("比较结果:", isGreater);
```

**输出结果**：

```
比较结果: true
```

## 2.6 空值 (null)

`null` 表示一个空值，通常用于表示变量没有值。

```matnn
var nullValue = null;
Console.log("空值:", nullValue);
```

**输出结果**：

```
空值: null
```

## 2.7 数组类型 (array)

数组是有序的值集合，使用方括号 `[]` 创建。

```matnn
var arrayValue = [1, 2, 3];
Console.log("数组:", arrayValue);
Console.log("数组长度:", arrayValue.length);
Console.log("第一个元素:", arrayValue[0]);
```

**输出结果**：

```
数组: [1, 2, 3]
数组长度: 3
第一个元素: 1
```

## 2.8 对象类型 (object)

对象是键值对的集合，使用花括号 `{}` 创建。

```matnn
var objectValue = {name: "Alice", age: 30};
Console.log("对象:", objectValue);
Console.log("姓名:", objectValue.name);
Console.log("年龄:", objectValue.age);
```

**输出结果**：

```
对象: {name: "Alice", age: 30}
姓名: Alice
年龄: 30
```

## 2.9 函数类型 (function)

函数是可执行的代码块，可以作为值传递。

```matnn
var func = function() {
    return "Hello";
};
Console.log("函数结果:", func());
```

**输出结果**：

```
函数结果: Hello
```

## 2.10 类型转换

Matnn 会自动进行类型转换，也可以手动进行类型转换。

### 自动类型转换

```matnn
var num = 10;
var str = "20";
var result = num + str;
Console.log("自动转换:", result);
```

**输出结果**：

```
自动转换: 1020
```

### 手动类型转换

使用 `Number()`、`String()`、`Boolean()` 进行类型转换：

```matnn
var strNum = "42";
var num = Number(strNum);
Console.log("字符串转数字:", num);

var bool = true;
var strBool = String(bool);
Console.log("布尔转字符串:", strBool);
```

**输出结果**：

```
字符串转数字: 42
布尔转字符串: true
```

## 2.11 本章小结

本章介绍了 Matnn 的变量声明和数据类型：

- 使用 `var` 或 `let` 声明变量
- Matnn 是动态类型语言
- 支持 number、string、boolean、null、array、object、function 类型
- 可以自动或手动进行类型转换
