# 第3章：运算符

## 3.1 算术运算符

Matnn 支持基本的算术运算：

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `%` | 取模（余数） | `a % b` |

```matnn
var a = 10;
var b = 3;

Console.log("算术运算符:");
Console.log("a + b =", a + b);
Console.log("a - b =", a - b);
Console.log("a * b =", a * b);
Console.log("a / b =", a / b);
Console.log("a % b =", a % b);
```

**输出结果**：

```
算术运算符:
a + b = 13
a - b = 7
a * b = 30
a / b = 3.3333333333333335
a % b = 1
```

## 3.2 比较运算符

比较运算符用于比较两个值，返回布尔值：

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `<` | 小于 | `a < b` |
| `>` | 大于 | `a > b` |
| `<=` | 小于等于 | `a <= b` |
| `>=` | 大于等于 | `a >= b` |

```matnn
var a = 10;
var b = 3;

Console.log("比较运算符:");
Console.log("a == b:", a == b);
Console.log("a != b:", a != b);
Console.log("a < b:", a < b);
Console.log("a > b:", a > b);
```

**输出结果**：

```
比较运算符:
a == b: false
a != b: true
a < b: false
a > b: true
```

## 3.3 逻辑运算符

逻辑运算符用于组合布尔表达式：

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `&&` | 逻辑与 | `a && b` |
| `\|\|` | 逻辑或 | `a \|\| b` |
| `!` | 逻辑非 | `!a` |

```matnn
Console.log("逻辑运算符:");
Console.log("true && false:", true && false);
Console.log("true || false:", true || false);
Console.log("!true:", !true);
```

**输出结果**：

```
逻辑运算符:
true && false: false
true || false: true
!true: false
```

### 短路求值

逻辑运算符支持短路求值：

- `&&`：如果第一个操作数为 `false`，则不计算第二个操作数
- `\|\|`：如果第一个操作数为 `true`，则不计算第二个操作数

```matnn
var x = 0;
var result = (x > 0) && (x++ > 0);
Console.log("x =", x);
```

**输出结果**：

```
x = 0
```

## 3.4 赋值运算符

赋值运算符用于给变量赋值：

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `=` | 赋值 | `x = 10` |
| `+=` | 加赋值 | `x += 5` |
| `-=` | 减赋值 | `x -= 5` |
| `*=` | 乘赋值 | `x *= 5` |
| `/=` | 除赋值 | `x /= 5` |
| `%=` | 取模赋值 | `x %= 5` |

```matnn
var x = 10;
x += 5;
Console.log("x += 5 =", x);

x *= 2;
Console.log("x *= 2 =", x);
```

**输出结果**：

```
x += 5 = 15
x *= 2 = 30
```

## 3.5 自增自减运算符

| 运算符 | 描述 |
|--------|------|
| `++` | 自增（增加1） |
| `--` | 自减（减少1） |

### 前缀和后缀

```matnn
var i = 0;
Console.log("i++ =", i++);
Console.log("i =", i);

var j = 0;
Console.log("++j =", ++j);
Console.log("j =", j);
```

**输出结果**：

```
i++ = 0
i = 1
++j = 1
j = 1
```

## 3.6 运算符优先级

运算符按照以下优先级从高到低执行：

1. 括号 `()`
2. 自增/自减 `++` `--`
3. 逻辑非 `!`
4. 乘法/除法/取模 `*` `/` `%`
5. 加法/减法 `+` `-`
6. 比较 `<` `>` `<=` `>=`
7. 等于/不等于 `==` `!=`
8. 逻辑与 `&&`
9. 逻辑或 `\|\|`
10. 赋值 `=` `+=` `-=` 等

```matnn
var result = 10 + 5 * 2;
Console.log("10 + 5 * 2 =", result);

var result2 = (10 + 5) * 2;
Console.log("(10 + 5) * 2 =", result2);
```

**输出结果**：

```
10 + 5 * 2 = 20
(10 + 5) * 2 = 30
```

- 逻辑运算符：`&&` `\|\|` `!`
