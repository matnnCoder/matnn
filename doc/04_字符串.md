# 第4章：字符串

## 4.1 字符串基础

字符串是字符的序列，在 Matnn 中使用双引号 `"` 或反引号 `` ` `` 包裹。

```matnn
var greeting = "Hello";
var name = "Matnn";
```

### 字符串长度

使用 `length` 属性获取字符串长度：

```matnn
var str = "Hello, Matnn!";
Console.log("字符串长度:", str.length);
```

**输出结果**：

```
字符串长度: 13
```

## 4.2 字符串拼接

使用 `+` 运算符拼接字符串：

```matnn
var greeting = "Hello";
var name = "Matnn";
var message = greeting + ", " + name + "!";
Console.log("字符串拼接:", message);
```

**输出结果**：

```
字符串拼接: Hello, Matnn!
```

## 4.3 模板字符串

模板字符串使用反引号 `` ` `` 创建，支持多行字符串和变量插值：

```matnn
var name = "Alice";
var age = 30;
var city = "Beijing";

var intro = `My name is ${name}, I am ${age} years old, and I live in ${city}.`;
Console.log("模板字符串:", intro);
```

**输出结果**：

```
模板字符串: My name is Alice, I am 30 years old, and I live in Beijing.
```

### 多行字符串

```matnn
var multiLine = `这是第一行
这是第二行
这是第三行`;
Console.log("多行字符串:", multiLine);
```

**输出结果**：

```
多行字符串: 这是第一行
这是第二行
这是第三行
```

## 4.4 字符串方法

### 获取字符

```matnn
var str = "abcdef";
Console.log("charAt(0):", str.charAt(0));
Console.log("charCodeAt(0):", str.charCodeAt(0));
```

**输出结果**：

```
charAt(0): a
charCodeAt(0): 97
```

### 查找字符串

```matnn
var str = "Hello, World!";
Console.log("indexOf('o'):", str.indexOf('o'));
Console.log("lastIndexOf('o'):", str.lastIndexOf('o'));
Console.log("includes('World'):", str.includes('World'));
```

**输出结果**：

```
indexOf('o'): 4
lastIndexOf('o'): 8
includes('World'): true
```

### 提取子字符串

```matnn
var str = "Hello, World!";
Console.log("slice(0, 5):", str.slice(0, 5));
Console.log("substring(0, 5):", str.substring(0, 5));
Console.log("substr(7, 5):", str.substr(7, 5));
```

**输出结果**：

```
slice(0, 5): Hello
substring(0, 5): Hello
substr(7, 5): World
```

### 大小写转换

```matnn
var str = "Hello, World!";
Console.log("toLowerCase():", str.toLowerCase());
Console.log("toUpperCase():", str.toUpperCase());
```

**输出结果**：

```
toLowerCase(): hello, world!
toUpperCase(): HELLO, WORLD!
```

### 去除空白

```matnn
var str = "  Hello, World!  ";
Console.log("trim():", str.trim());
```

**输出结果**：

```
trim(): Hello, World!
```

### 替换字符串

```matnn
var str = "Hello, World!";
Console.log("replace('World', 'Matnn'):", str.replace('World', 'Matnn'));
```

**输出结果**：

```
replace('World', 'Matnn'): Hello, Matnn!
```

### 分割字符串

```matnn
var str = "apple,banana,orange";
Console.log("split(','):", str.split(','));
```

**输出结果**：

```
split(','): ["apple", "banana", "orange"]
```

## 4.5 字符串比较

```matnn
var str1 = "abc";
var str2 = "def";
var str3 = "abc";

Console.log("str1 == str2:", str1 == str2);
Console.log("str1 == str3:", str1 == str3);
Console.log("str1 < str2:", str1 < str2);
```

**输出结果**：

```
str1 == str2: false
str1 == str3: true
str1 < str2: true
```

- 使用 `+` 运算符拼接字符串
