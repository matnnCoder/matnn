# 第5章：数组

## 5.1 数组基础

数组是有序的值集合，使用方括号 `[]` 创建。

```matnn
var arr = [1, 2, 3, 4, 5];
```

### 数组长度

使用 `length` 属性获取数组长度：

```matnn
var arr = [1, 2, 3, 4, 5];
Console.log("数组:", arr);
Console.log("数组长度:", arr.length);
```

**输出结果**：

```
数组: [1, 2, 3, 4, 5]
数组长度: 5
```

### 访问数组元素

使用索引访问数组元素，索引从0开始：

```matnn
var arr = [1, 2, 3, 4, 5];
Console.log("第一个元素:", arr[0]);
Console.log("最后一个元素:", arr[arr.length - 1]);
```

**输出结果**：

```
第一个元素: 1
最后一个元素: 5
```

### 修改数组元素

```matnn
var arr = [1, 2, 3];
arr[2] = 30;
Console.log("修改后的数组:", arr);
```

**输出结果**：

```
修改后的数组: [1, 2, 30]
```

## 5.2 数组方法

### join()

将数组元素拼接为字符串：

```matnn
var arr = [1, 2, 3];
var joined = arr.join(",");
Console.log("join(','):", joined);
```

**输出结果**：

```
join(','): 1,2,3
```

### push()

在数组末尾添加元素：

```matnn
var arr = [1, 2, 3];
arr.push(4);
Console.log("push(4):", arr);
```

**输出结果**：

```
push(4): [1, 2, 3, 4]
```

### pop()

移除并返回数组末尾元素：

```matnn
var arr = [1, 2, 3];
var last = arr.pop();
Console.log("pop():", last);
Console.log("数组:", arr);
```

**输出结果**：

```
pop(): 3
数组: [1, 2]
```

### shift()

移除并返回数组第一个元素：

```matnn
var arr = [1, 2, 3];
var first = arr.shift();
Console.log("shift():", first);
Console.log("数组:", arr);
```

**输出结果**：

```
shift(): 1
数组: [2, 3]
```

### unshift()

在数组开头添加元素：

```matnn
var arr = [1, 2, 3];
arr.unshift(0);
Console.log("unshift(0):", arr);
```

**输出结果**：

```
unshift(0): [0, 1, 2, 3]
```

### slice()

提取数组的一部分：

```matnn
var arr = [1, 2, 3, 4, 5];
var sliced = arr.slice(1, 3);
Console.log("slice(1, 3):", sliced);
```

**输出结果**：

```
slice(1, 3): [2, 3]
```

### concat()

合并数组：

```matnn
var arr1 = [1, 2];
var arr2 = [3, 4];
var combined = arr1.concat(arr2);
Console.log("concat:", combined);
```

**输出结果**：

```
concat: [1, 2, 3, 4]
```

### reverse()

反转数组：

```matnn
var arr = [1, 2, 3];
arr.reverse();
Console.log("reverse():", arr);
```

**输出结果**：

```
reverse(): [3, 2, 1]
```

## 5.3 数组遍历

### for 循环

```matnn
var arr = [1, 2, 3, 4, 5];
var sum = 0;
for (var i = 0; i < arr.length; i++) {
    sum += arr[i];
}
Console.log("数组元素和:", sum);
```

**输出结果**：

```
数组元素和: 15
```

### for-in 循环

```matnn
var arr = ["apple", "banana", "orange"];
for (var index in arr) {
    Console.log("index:", index, ", value:", arr[index]);
}
```

**输出结果**：

```
index: 0 , value: apple
index: 1 , value: banana
index: 2 , value: orange
```

## 5.4 多维数组

```matnn
var matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];
Console.log("matrix[0][0]:", matrix[0][0]);
Console.log("matrix[1][2]:", matrix[1][2]);
```

**输出结果**：

```
matrix[0][0]: 1
matrix[1][2]: 6
```
