# 第6章：对象

## 6.1 对象基础

对象是键值对的集合，使用花括号 `{}` 创建。

```matnn
var person = {
    name: "Alice",
    age: 30,
    city: "Shanghai"
};
```

### 访问对象属性

使用点符号或方括号访问对象属性：

```matnn
var person = {
    name: "Alice",
    age: 30,
    city: "Shanghai"
};

Console.log("对象:", person);
Console.log("姓名:", person.name);
Console.log("年龄:", person.age);
Console.log("城市:", person.city);
```

**输出结果**：

```
对象: {name: "Alice", age: 30, city: "Shanghai"}
姓名: Alice
年龄: 30
城市: Shanghai
```

### 使用方括号访问

```matnn
var person = {name: "Alice", age: 30};
var key = "name";
Console.log("person[key]:", person[key]);
```

**输出结果**：

```
person[key]: Alice
```

## 6.2 修改对象属性

```matnn
var person = {name: "Alice", age: 30};
person.age = 31;
Console.log("修改年龄后的对象:", person);
```

**输出结果**：

```
修改年龄后的对象: {name: "Alice", age: 31}
```

## 6.3 添加对象属性

```matnn
var person = {name: "Alice", age: 30};
person.job = "Developer";
person["hobby"] = "coding";
Console.log("添加属性后的对象:", person);
```

**输出结果**：

```
添加属性后的对象: {name: "Alice", age: 30, job: "Developer", hobby: "coding"}
```

## 6.4 删除对象属性

```matnn
var person = {name: "Alice", age: 30, city: "Shanghai"};
delete person.city;
Console.log("删除属性后的对象:", person);
```

**输出结果**：

```
删除属性后的对象: {name: "Alice", age: 30}
```

## 6.5 对象遍历

使用 `for-in` 循环遍历对象的属性：

```matnn
var person = {
    name: "Alice",
    age: 30,
    city: "Shanghai",
    job: "Developer"
};

for (var key in person) {
    Console.log("key:", key, ", value:", person[key]);
}
```

**输出结果**：

```
key: name , value: Alice
key: age , value: 30
key: city , value: Shanghai
key: job , value: Developer
```

### 检查自有属性

使用 `hasOwnProperty` 检查属性是否为对象自有属性：

```matnn
var car = {
    brand: "Tesla",
    model: "Model 3",
    year: 2023
};

for (var prop in car) {
    if (car.hasOwnProperty(prop)) {
        Console.log("自有属性: ", prop, "=", car[prop]);
    }
}
```

**输出结果**：

```
自有属性:  brand = Tesla
自有属性:  model = Model 3
自有属性:  year = 2023
```

## 6.6 对象方法

对象可以包含方法：

```matnn
var person = {
    name: "Alice",
    age: 30,
    greet: function() {
        return "Hello, my name is " + this.name;
    }
};

Console.log("person.greet():", person.greet());
```

**输出结果**：

```
person.greet(): Hello, my name is Alice
```

## 6.7 嵌套对象

```matnn
var company = {
    name: "Tech Corp",
    address: {
        street: "Main Street",
        city: "Beijing",
        zipCode: "100000"
    },
    employees: [
        {name: "Alice", age: 30},
        {name: "Bob", age: 25}
    ]
};

Console.log("公司名称:", company.name);
Console.log("公司地址:", company.address.city);
Console.log("第一个员工:", company.employees[0].name);
```

**输出结果**：

```
公司名称: Tech Corp
公司地址: Beijing
第一个员工: Alice
```

## 6.8 this 关键字

在对象方法中，`this` 指向当前对象：

```matnn
var car = {
    brand: "Tesla",
    model: "Model 3",
    describe: function() {
        return "This is a " + this.brand + " " + this.model;
    }
};

Console.log("car.describe():", car.describe());
```

**输出结果**：

```
car.describe(): This is a Tesla Model 3
```

- 使用点符号或方括号访问属性
- 修改、添加和删除对象属性
- 使用 `for-in` 循环遍历对象
- 使用 `hasOwnProperty` 检查自有属性
- 对象可以包含方法
