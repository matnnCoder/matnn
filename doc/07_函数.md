# 第7章：函数

## 7.1 函数声明

使用 `function` 关键字声明函数：

```matnn
function add(a, b) {
    return a + b;
}

function multiply(a, b) {
    return a * b;
}

function greet(name) {
    return "Hello, " + name + "!";
}
```

### 调用函数

```matnn
Console.log("add(2, 3) =", add(2, 3));
Console.log("multiply(4, 5) =", multiply(4, 5));
Console.log("greet(Matnn) =", greet("Matnn"));
```

**输出结果**：

```
add(2, 3) = 5
multiply(4, 5) = 20
greet(Matnn) = Hello, Matnn!
```

## 7.2 函数表达式

将函数赋值给变量：

```matnn
var add = function(a, b) {
    return a + b;
};

Console.log("add(2, 3) =", add(2, 3));
```

**输出结果**：

```
add(2, 3) = 5
```

## 7.3 箭头函数

箭头函数提供了更简洁的语法：

```matnn
var add = (a, b) => a + b;
var doubleNum = x => x * 2;
var greet = name => `Hello, ${name}!`;
```

### 调用箭头函数

```matnn
Console.log("add(2, 3) =", add(2, 3));
Console.log("doubleNum(5) =", doubleNum(5));
Console.log("greet(Matnn) =", greet("Matnn"));
```

**输出结果**：

```
add(2, 3) = 5
doubleNum(5) = 10
greet(Matnn) = Hello, Matnn!
```

### 多行箭头函数

使用花括号包裹多行代码：

```matnn
var sumArray = arr => {
    var total = 0;
    for (var i = 0; i < arr.length; i++) {
        total = total + arr[i];
    }
    return total;
};

Console.log("sumArray([1,2,3,4,5]) =", sumArray([1, 2, 3, 4, 5]));
```

**输出结果**：

```
sumArray([1,2,3,4,5]) = 15
```

### 返回对象的箭头函数

```matnn
var createPerson = (name, age) => ({name: name, age: age});
var p = createPerson("Alice", 30);
Console.log("createPerson(Alice, 30).name =", p.name);
Console.log("createPerson(Alice, 30).age =", p.age);
```

**输出结果**：

```
createPerson(Alice, 30).name = Alice
createPerson(Alice, 30).age = 30
```

## 7.4 参数与返回值

### 参数

函数可以接受零个或多个参数：

```matnn
function sum(a, b, c) {
    return a + b + c;
}

Console.log("sum(1, 2, 3) =", sum(1, 2, 3));
```

**输出结果**：

```
sum(1, 2, 3) = 6
```

### 返回值

使用 `return` 语句返回值：

```matnn
function isEven(n) {
    return n % 2 == 0;
}

Console.log("isEven(4) =", isEven(4));
Console.log("isEven(5) =", isEven(5));
```

**输出结果**：

```
isEven(4) = true
isEven(5) = false
```

### 无返回值

如果没有 `return` 语句，函数返回 `null`：

```matnn
function sayHello() {
    Console.log("Hello!");
}

var result = sayHello();
Console.log("result:", result);
```

**输出结果**：

```
Hello!
result: null
```

## 7.5 函数作为值

函数可以作为参数传递或作为返回值：

```matnn
function applyOperation(a, b, operation) {
    return operation(a, b);
}

var result = applyOperation(10, 5, function(x, y) {
    return x - y;
});

Console.log("applyOperation(10, 5, subtract) =", result);
```

**输出结果**：

```
applyOperation(10, 5, subtract) = 5
```

## 7.6 函数方法

### call()

调用函数并指定 `this` 值：

```matnn
var person = {name: "Alice"};

function greet(greeting) {
    return greeting + ", " + this.name + "!";
}

Console.log("greet.call(person, 'Hello'):", greet.call(person, "Hello"));
```

**输出结果**：

```
greet.call(person, 'Hello'): Hello, Alice!
```

### apply()

调用函数并指定 `this` 值和参数数组：

```matnn
function sum(a, b, c) {
    return a + b + c;
}

var args = [1, 2, 3];
Console.log("sum.apply(null, args):", sum.apply(null, args));
```

**输出结果**：

```
sum.apply(null, args): 6
```

### bind()

创建新函数并绑定 `this` 值：

```matnn
var person = {name: "Alice"};

function greet() {
    return "Hello, " + this.name + "!";
}

var greetAlice = greet.bind(person);
Console.log("greetAlice():", greetAlice());
```

**输出结果**：

```
greetAlice(): Hello, Alice!
```
