# 第8章：控制流程

## 8.1 if-else 语句

`if-else` 语句用于条件判断：

```matnn
var score = 85;
var grade;

if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B";
} else if (score >= 70) {
    grade = "C";
} else {
    grade = "D";
}

Console.log("分数:", score);
Console.log("等级:", grade);
```

**输出结果**：

```
分数: 85
等级: B
```

### 简单 if-else

```matnn
var age = 20;
if (age >= 18) {
    Console.log("成年人");
} else {
    Console.log("未成年人");
}
```

**输出结果**：

```
成年人
```

## 8.2 for 循环

### 基本 for 循环

```matnn
Console.log("基本 for 循环:");
var sum = 0;
for (var i = 0; i < 10; i++) {
    sum = sum + i;
}
Console.log("0到9的和:", sum);
```

**输出结果**：

```
基本 for 循环:
0到9的和: 45
```

### 数组遍历

```matnn
Console.log("\n数组遍历:");
var arr = [1, 2, 3, 4, 5];
var total = 0;
for (var j = 0; j < arr.length; j++) {
    total = total + arr[j];
}
Console.log("数组元素和:", total);
```

**输出结果**：

```
数组遍历:
数组元素和: 15
```

## 8.3 while 循环

`while` 循环在条件为 `true` 时执行：

```matnn
Console.log("while 循环:");
var count = 0;
while (count < 5) {
    Console.log("count =", count);
    count++;
}
```

**输出结果**：

```
while 循环:
count = 0
count = 1
count = 2
count = 3
count = 4
```

## 8.4 do-while 循环

`do-while` 循环至少执行一次：

```matnn
Console.log("do-while 循环:");
var num = 0;
do {
    Console.log("num =", num);
    num++;
} while (num < 3);
```

**输出结果**：

```
do-while 循环:
num = 0
num = 1
num = 2
```

## 8.5 switch-case 语句

`switch` 语句用于多条件判断：

```matnn
var day = 3;
var dayName;

switch (day) {
    case 1:
        dayName = "星期一";
        break;
    case 2:
        dayName = "星期二";
        break;
    case 3:
        dayName = "星期三";
        break;
    case 4:
        dayName = "星期四";
        break;
    case 5:
        dayName = "星期五";
        break;
    default:
        dayName = "周末";
        break;
}

Console.log("今天是:", dayName);
```

**输出结果**：

```
今天是: 星期三
```

## 8.6 break 和 continue

### break

`break` 语句用于跳出循环：

```matnn
Console.log("使用 break:");
for (var i = 0; i < 10; i++) {
    if (i == 5) {
        break;
    }
    Console.log("i =", i);
}
```

**输出结果**：

```
使用 break:
i = 0
i = 1
i = 2
i = 3
i = 4
```

### continue

`continue` 语句用于跳过当前迭代：

```matnn
Console.log("使用 continue:");
for (var i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;
    }
    Console.log("i =", i);
}
```

**输出结果**：

```
使用 continue:
i = 1
i = 3
i = 5
i = 7
i = 9
```

## 8.7 for-in 循环

`for-in` 循环用于遍历对象或数组：

### 遍历对象

```matnn
Console.log("=== for-in 循环遍历对象 ===");

var person = {
    name: "Alice",
    age: 30,
    city: "Shanghai",
    job: "Developer"
};

for (var key in person) {
    Console.log("key:", key, ", value:", person[key]);
}
```

**输出结果**：

```
=== for-in 循环遍历对象 ===
key: name , value: Alice
key: age , value: 30
key: city , value: Shanghai
key: job , value: Developer
```

### 遍历数组

```matnn
Console.log("\n=== for-in 循环遍历数组 ===");

var arr = ["apple", "banana", "orange", "grape"];
for (var index in arr) {
    Console.log("index:", index, ", value:", arr[index]);
}
```

**输出结果**：

```
=== for-in 循环遍历数组 ===
index: 0 , value: apple
index: 1 , value: banana
index: 2 , value: orange
index: 3 , value: grape
```

## 8.8 本章小结

本章介绍了 Matnn 的控制流程：

- `if-else` 语句用于条件判断
- `for` 循环用于固定次数的迭代
- `while` 循环用于条件为真时的迭代
- `do-while` 循环至少执行一次
- `switch-case` 语句用于多条件判断
- `break` 用于跳出循环
- `continue` 用于跳过当前迭代
- `for-in` 用于遍历对象和数组
