# 第12章：类与继承

## 12.1 类定义

使用 `class` 关键字定义类：

```matnn
Console.log("=== 类定义 (class) ===");
class Person {
    constructor(n, a) {
        this.name = n;
        this.age = a;
    }
    greet() {
        return "Hello, my name is " + this.name + ", I'm " + this.age + " years old."
    }
    getInfo() {
        return {name: this.name, age: this.age}
    }
}
```

### 实例化类

使用 `new` 关键字创建类的实例：

```matnn
var p1 = new Person("Alice", 30);
Console.log("p1.greet():", p1.greet());
Console.log("p1.getInfo():", p1.getInfo());
Console.log("p1.name:", p1.name);
Console.log("p1.age:", p1.age);
```

**输出结果**：

```
p1.greet(): Hello, my name is Alice, I'm 30 years old.
p1.getInfo(): {name: "Alice", age: 30}
p1.name: Alice
p1.age: 30
```

## 12.2 修改实例属性

```matnn
Console.log("\n=== 修改实例属性 ===");
p1.age = 31;
Console.log("修改年龄后 p1.greet():", p1.greet());
```

**输出结果**：

```
修改年龄后 p1.greet(): Hello, my name is Alice, I'm 31 years old.
```

## 12.3 this 关键字

在类方法中，`this` 指向当前实例：

```matnn
Console.log("\n=== this 关键字 ===");
class Car {
    constructor(b, m) {
        this.brand = b;
        this.model = m;
    }
    describe() {
        return "This is a " + this.brand + " " + this.model
    }
}
var myCar = new Car("Tesla", "Model 3");
Console.log("myCar.describe():", myCar.describe());
```

**输出结果**：

```
myCar.describe(): This is a Tesla Model 3
```

## 12.4 类继承

使用 `extends` 关键字实现继承：

```matnn
Console.log("\n=== 类继承 (extends/super) ===");

class Animal {
    constructor(name) {
        this.name = name;
    }

    speak() {
        return this.name + " makes a noise.";
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        super(name);
        this.breed = breed;
    }

    speak() {
        return this.name + " barks. Breed: " + this.breed;
    }
}

class Cat extends Animal {
    constructor(name) {
        super(name);
    }

    speak() {
        return this.name + " meows.";
    }
}
```

### 使用继承的类

```matnn
var dog = new Dog("Buddy", "Golden Retriever");
Console.log("dog.speak():", dog.speak());

var cat = new Cat("Mittens");
Console.log("cat.speak():", cat.speak());
```

**输出结果**：

```
dog.speak(): Buddy barks. Breed: Golden Retriever
cat.speak(): Mittens meows.
```

## 12.5 静态方法

使用 `static` 关键字定义静态方法：

```matnn
Console.log("\n=== 静态方法 (static) ===");

class MathUtils {
    static add(a, b) {
        return a + b;
    }

    static multiply(a, b) {
        return a * b;
    }

    static square(n) {
        return n * n;
    }
}

Console.log("MathUtils.add(2, 3):", MathUtils.add(2, 3));
Console.log("MathUtils.multiply(4, 5):", MathUtils.multiply(4, 5));
Console.log("MathUtils.square(6):", MathUtils.square(6));
```

**输出结果**：

```
MathUtils.add(2, 3): 5
MathUtils.multiply(4, 5): 20
MathUtils.square(6): 36
```

## 12.6 多层继承

```matnn
Console.log("\n=== 多层继承 ===");

class Shape {
    constructor(color) {
        this.color = color;
    }

    getColor() {
        return this.color;
    }
}

class Circle extends Shape {
    constructor(color, radius) {
        super(color);
        this.radius = radius;
    }

    getArea() {
        return Math.PI * this.radius * this.radius;
    }
}

var circle = new Circle("red", 5);
Console.log("circle.getColor():", circle.getColor());
Console.log("circle.getArea():", circle.getArea());
```

**输出结果**：

```
circle.getColor(): red
circle.getArea(): 78.53981633974483
```
