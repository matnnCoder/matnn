# 第13章：模块系统

## 13.1 export 导出

使用 `export` 关键字导出变量、函数或类：

### 导出变量

```matnn
export const VALUE = 42;
```

### 导出函数

```matnn
export function sum(a, b) {
    return a + b;
}
```

### 导出类

```matnn
export class Calculator {
    add(a, b) {
        return a + b;
    }
    multiply(a, b) {
        return a * b;
    }
}
```

## 13.2 import 导入

使用 `import` 关键字导入模块：

```matnn
import "./simple_module.mt" as mod;

Console.log("mod.VALUE:", mod.VALUE);
Console.log("mod.sum(2, 3):", mod.sum(2, 3));
```

**输出结果**：

```
mod.VALUE: 42
mod.sum(2, 3): 5
```

## 13.3 导入多个成员

```matnn
import "./math_module.mt" as math;

Console.log("math.add(2, 3):", math.add(2, 3));
Console.log("math.subtract(5, 2):", math.subtract(5, 2));
Console.log("math.multiply(4, 5):", math.multiply(4, 5));
```

## 13.4 创建模块文件

### simple_module.mt

```matnn
export const VALUE = 42;

export function sum(a, b) {
    return a + b;
}
```

### math_module.mt

```matnn
export function add(a, b) {
    return a + b;
}

export function subtract(a, b) {
    return a - b;
}

export function multiply(a, b) {
    return a * b;
}

export function divide(a, b) {
    return a / b;
}
```

## 13.5 模块路径

模块路径支持相对路径和绝对路径：

- `import "./module.mt" as mod` - 相对路径
- `import "../utils/module.mt" as mod` - 上级目录

## 13.6 本章小结

本章介绍了 Matnn 的模块系统：

- 使用 `export` 关键字导出变量、函数或类
- 使用 `import` 关键字导入模块
- 使用 `as` 关键字为模块指定别名
- 模块路径支持相对路径和绝对路径
