# 第14章：异步任务

## 14.1 Task 对象概述

`Task` 对象用于创建和管理异步任务，支持同步执行和异步执行两种模式。

## 14.2 同步任务 (run)

使用 `run()` 方法同步执行任务：

```matnn
Console.log("=== 同步任务 (run) ===");

var t1 = Task.new(() => {
    var sum = 0;
    for (var i = 1; i <= 100; i++) {
        sum += i;
    }
    return sum;
});

t1.run();
Console.log("任务结果:", t1.data);
Console.log("期望结果: 5050");
```

**输出结果**：

```
=== 同步任务 (run) ===
任务结果: 5050
期望结果: 5050
```

## 14.3 异步任务 (start + wait)

使用 `start()` 方法启动异步任务，使用 `Task.wait()` 等待任务完成：

```matnn
Console.log("=== 异步任务 (start + wait) ===");

var t1 = Task.new(() => {
    var sum = 0;
    for (var i = 1; i <= 100; i++) {
        sum += i;
    }
    Console.log("任务内部结果:", sum);
    return sum;
});

t1.start();
Console.log("start 返回后立即执行，不阻塞");
Task.wait(t1);
Console.log("任务完成，结果:", t1.data);
```

**输出结果**：

```
=== 异步任务 (start + wait) ===
start 返回后立即执行，不阻塞
任务内部结果: 5050
任务完成，结果: 5050
```

## 14.4 并发任务

```matnn
Console.log("=== 并发任务 ===");

var t1 = Task.new(() => {
    var sum = 0;
    for (var i = 1; i <= 100; i++) {
        sum += i;
    }
    return sum;
});

var t2 = Task.new(() => {
    var product = 1;
    for (var i = 1; i <= 10; i++) {
        product *= i;
    }
    return product;
});

t1.start();
t2.start();

Task.wait(t1);
Task.wait(t2);

Console.log("任务1结果:", t1.data);
Console.log("任务2结果:", t2.data);
```

**输出结果**：

```
=== 并发任务 ===
任务1结果: 5050
任务2结果: 3628800
```

## 14.5 任务参数

```matnn
Console.log("=== 任务参数 ===");

var t1 = Task.new((param) => {
    var sum = 0;
    for (var i = 1; i <= param; i++) {
        sum += i;
    }
    return sum;
});

t1.put("n", 100);
t1.run();
Console.log("任务结果:", t1.data);
```

**输出结果**：

```
=== 任务参数 ===
任务结果: 5050
```

## 14.6 回调函数

```matnn
Console.log("=== 回调函数 ===");

var t1 = Task.new(() => {
    return "任务完成";
});

t1.setCallback((result) => {
    Console.log("回调函数被调用:", result);
});

t1.run();
```

**输出结果**：

```
=== 回调函数 ===
回调函数被调用: 任务完成
```

## 14.7 HTTP 异步请求

```matnn
Console.log("=== HTTP 异步请求 ===");

var t1 = Task.new(() => {
    var response = Http.get("http://httpbin.org/get");
    return response;
});

t1.start();
Task.wait(t1);
Console.log("HTTP 响应:", t1.data);
```

## 14.8 本章小结

本章介绍了 Matnn 的异步任务系统：

- 使用 `Task.new()` 创建任务
- 使用 `run()` 同步执行任务
- 使用 `start()` 启动异步任务
- 使用 `Task.wait()` 等待任务完成
- 使用 `put()` 设置任务参数
- 使用 `setCallback()` 设置回调函数
- 支持并发执行多个任务
