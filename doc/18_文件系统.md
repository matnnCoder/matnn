# 第18章：文件系统

## 18.1 Fs 对象概述

`Fs` 对象提供了文件系统操作功能，支持文件读写、目录操作等。

## 18.2 创建目录

```matnn
Console.log("=== Fs 文件系统操作 ===");

var testDir = "./test_fs_dir";

Console.log("\n--- 创建目录 ---");
Fs.mkdir(testDir);
Console.log("目录", testDir, "创建成功");
```

**输出结果**：

```
目录 ./test_fs_dir 创建成功
```

## 18.3 检查目录是否存在

```matnn
Console.log("\n--- 检查目录是否存在 ---");
var dirExists = Fs.exists(testDir);
Console.log("目录", testDir, "存在:", dirExists);
```

**输出结果**：

```
目录 ./test_fs_dir 存在: true
```

## 18.4 写入文件

```matnn
var testFile = "./test_fs.txt";

Console.log("\n--- 写入文件 ---");
Fs.writeFile(testFile, "Hello, Matnn Fs!");
Console.log("文件", testFile, "写入成功");
```

**输出结果**：

```
文件 ./test_fs.txt 写入成功
```

## 18.5 读取文件

```matnn
Console.log("\n--- 读取文件 ---");
var content = Fs.readFile(testFile);
Console.log("文件内容:", content);
```

**输出结果**：

```
文件内容: Hello, Matnn Fs!
```

## 18.6 追加写入文件

```matnn
Console.log("\n--- 追加写入文件 ---");
Fs.appendFile(testFile, "\n追加的内容");
var content2 = Fs.readFile(testFile);
Console.log("追加后文件内容:", content2);
```

**输出结果**：

```
追加后文件内容: Hello, Matnn Fs!
追加的内容
```

## 18.7 获取文件信息

```matnn
Console.log("\n--- 获取文件信息 ---");
var stat = Fs.stat(testFile);
Console.log("文件信息:", stat);
```

**输出结果**：

```
文件信息: {...}
```

## 18.8 重命名文件

```matnn
Console.log("\n--- 重命名文件 ---");
var newFile = "./test_fs_renamed.txt";
Fs.rename(testFile, newFile);
Console.log("文件重命名为:", newFile);
```

**输出结果**：

```
文件重命名为: ./test_fs_renamed.txt
```

## 18.9 删除文件

```matnn
Console.log("\n--- 删除文件 ---");
Fs.remove(newFile);
Console.log("文件", newFile, "删除成功");
```

**输出结果**：

```
文件 ./test_fs_renamed.txt 删除成功
```

## 18.10 删除目录

```matnn
Console.log("\n--- 删除目录 ---");
Fs.rmdir(testDir);
Console.log("目录", testDir, "删除成功");
```

**输出结果**：

```
目录 ./test_fs_dir 删除成功
```

## 18.11 读取目录内容

```matnn
Console.log("\n--- 读取目录内容 ---");
var files = Fs.readDir(".");
Console.log("当前目录内容:", files);
```

**输出结果**：

```
当前目录内容: ["file1.mt", "file2.mt", ...]
```

## 18.12 本章小结

本章介绍了 Matnn 的文件系统操作：

- `Fs.mkdir()` 创建目录
- `Fs.exists()` 检查路径是否存在
- `Fs.writeFile()` 写入文件
- `Fs.readFile()` 读取文件
- `Fs.appendFile()` 追加写入文件
- `Fs.stat()` 获取文件信息
- `Fs.rename()` 重命名文件
- `Fs.remove()` 删除文件
- `Fs.rmdir()` 删除目录
- `Fs.readDir()` 读取目录内容
