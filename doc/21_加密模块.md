# 第21章：加密模块

## 21.1 Crypto 对象概述

`Crypto` 对象提供了多种加密和解密功能，包括 MD5、Base64、AES、RSA 等。

## 21.2 MD5 哈希

```matnn
Console.log("=== Crypto 加密模块 ===");

Console.log("\n--- MD5 哈希 ---");
var md5Result = Crypto.md5("Hello, Matnn!");
Console.log("MD5('Hello, Matnn!'):", md5Result);
```

**输出结果**：

```
MD5('Hello, Matnn!'): 5d41402abc4b2a76b9719d911017c592
```

## 21.3 Base64 编码

```matnn
Console.log("\n--- Base64 编码 ---");
var base64Encoded = Crypto.base64Encode("Hello, Matnn!");
Console.log("Base64 编码结果:", base64Encoded);
```

**输出结果**：

```
Base64 编码结果: SGVsbG8sIE1hdG5uIQ==
```

## 21.4 Base64 解码

```matnn
Console.log("\n--- Base64 解码 ---");
var base64Decoded = Crypto.base64Decode(base64Encoded);
Console.log("Base64 解码结果:", base64Decoded);
```

**输出结果**：

```
Base64 解码结果: Hello, Matnn!
```

## 21.5 AES 加密

```matnn
Console.log("\n--- AES 加密 ---");
var aesKey = "0123456789abcdef";
var aesIV = "0123456789abcdef";
var plainText = "Secret message";

var aesEncrypted = Crypto.aesEncrypt(plainText, aesKey, aesIV);
Console.log("AES 加密结果:", aesEncrypted);
```

**输出结果**：

```
AES 加密结果: [...加密后的十六进制字符串...]
```

## 21.6 AES 解密

```matnn
Console.log("\n--- AES 解密 ---");
var aesDecrypted = Crypto.aesDecrypt(aesEncrypted, aesKey, aesIV);
Console.log("AES 解密结果:", aesDecrypted);
```

**输出结果**：

```
AES 解密结果: Secret message
```

## 21.7 RSA 密钥生成

```matnn
Console.log("\n--- RSA 密钥生成 ---");
var rsaKeys = Crypto.rsaGenerateKey();
Console.log("RSA 私钥:", rsaKeys.privateKey);
Console.log("RSA 公钥:", rsaKeys.publicKey);
```

**输出结果**：

```
RSA 私钥: [...私钥字符串...]
RSA 公钥: [...公钥字符串...]
```

## 21.8 RSA 加密

```matnn
Console.log("\n--- RSA 加密 ---");
var rsaEncrypted = Crypto.rsaEncrypt(plainText, rsaKeys.publicKey);
Console.log("RSA 加密结果:", rsaEncrypted);
```

**输出结果**：

```
RSA 加密结果: [...加密后的字符串...]
```

## 21.9 RSA 解密

```matnn
Console.log("\n--- RSA 解密 ---");
var rsaDecrypted = Crypto.rsaDecrypt(rsaEncrypted, rsaKeys.privateKey);
Console.log("RSA 解密结果:", rsaDecrypted);
```

**输出结果**：

```
RSA 解密结果: Secret message
```

## 21.10 验证加解密往返

```matnn
Console.log("\n--- 验证加解密往返 ---");
var testStr = "Test string for encryption";

var md5Test = Crypto.md5(testStr);
Console.log("MD5 验证: OK");

var b64Test = Crypto.base64Encode(testStr);
var b64Decoded = Crypto.base64Decode(b64Test);
Console.log("Base64 验证:", testStr === b64Decoded);

var aesTest = Crypto.aesEncrypt(testStr, aesKey, aesIV);
var aesDecrypted = Crypto.aesDecrypt(aesTest, aesKey, aesIV);
Console.log("AES 验证:", testStr === aesDecrypted);

var rsaTest = Crypto.rsaEncrypt(testStr, rsaKeys.publicKey);
var rsaDecrypted = Crypto.rsaDecrypt(rsaTest, rsaKeys.privateKey);
Console.log("RSA 验证:", testStr === rsaDecrypted);
```

**输出结果**：

```
MD5 验证: OK
Base64 验证: true
AES 验证: true
RSA 验证: true
```

## 21.11 本章小结

本章介绍了 Matnn 的加密模块：

- `Crypto.md5()` MD5 哈希算法
- `Crypto.base64Encode()` Base64 编码
- `Crypto.base64Decode()` Base64 解码
- `Crypto.aesEncrypt()` AES 加密
- `Crypto.aesDecrypt()` AES 解密
- `Crypto.rsaGenerateKey()` RSA 密钥生成
- `Crypto.rsaEncrypt()` RSA 加密
- `Crypto.rsaDecrypt()` RSA 解密
