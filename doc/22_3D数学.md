# 第22章：3D数学

## 22.1 Vec 和 Mat 对象概述

Matnn 提供了向量（Vec）和矩阵（Mat）对象，用于进行 3D 数学计算。

## 22.2 创建向量

```matnn
Console.log("=== 3D 数学 - Vec 向量 ===");

Console.log("\n--- 创建向量 ---");
var v1 = new Vec(1, 2, 3);
var v2 = new Vec(4, 5, 6);
var v3 = new Vec(1, 0, 0);
var v4 = new Vec(0, 1, 0);

Console.log("v1:", v1);
Console.log("v2:", v2);
Console.log("v3:", v3);
Console.log("v4:", v4);
```

**输出结果**：

```
v1: Vec {x: 1, y: 2, z: 3}
v2: Vec {x: 4, y: 5, z: 6}
v3: Vec {x: 1, y: 0, z: 0}
v4: Vec {x: 0, y: 1, z: 0}
```

## 22.3 向量属性

```matnn
Console.log("\n--- 向量属性 ---");
Console.log("v1.x:", v1.x);
Console.log("v1.y:", v1.y);
Console.log("v1.z:", v1.z);
```

**输出结果**：

```
v1.x: 1
v1.y: 2
v1.z: 3
```

## 22.4 向量加法

```matnn
Console.log("\n--- 向量加法 ---");
var vAdd = Vec.add(v1, v2);
Console.log("v1 + v2:", vAdd);
```

**输出结果**：

```
v1 + v2: Vec {x: 5, y: 7, z: 9}
```

## 22.5 向量减法

```matnn
Console.log("\n--- 向量减法 ---");
var vSub = Vec.sub(v1, v2);
Console.log("v1 - v2:", vSub);
```

**输出结果**：

```
v1 - v2: Vec {x: -3, y: -3, z: -3}
```

## 22.6 向量标量乘法

```matnn
Console.log("\n--- 向量标量乘法 ---");
var vMul = Vec.mul(v1, 2);
Console.log("v1 * 2:", vMul);
```

**输出结果**：

```
v1 * 2: Vec {x: 2, y: 4, z: 6}
```

## 22.7 向量点积

```matnn
Console.log("\n--- 向量点积 ---");
var dot = Vec.dot(v1, v2);
Console.log("v1 · v2:", dot);
```

**输出结果**：

```
v1 · v2: 32
```

## 22.8 向量叉积

```matnn
Console.log("\n--- 向量叉积 ---");
var cross = Vec.cross(v3, v4);
Console.log("v3 × v4:", cross);
```

**输出结果**：

```
v3 × v4: Vec {x: 0, y: 0, z: 1}
```

## 22.9 向量长度

```matnn
Console.log("\n--- 向量长度 ---");
var len = Vec.length(v1);
Console.log("|v1|:", len);
```

**输出结果**：

```
|v1|: 3.7416573867739413
```

## 22.10 向量归一化

```matnn
Console.log("\n--- 向量归一化 ---");
var norm = Vec.normalize(v1);
Console.log("normalize(v1):", norm);
Console.log("|normalize(v1)|:", Vec.length(norm));
```

**输出结果**：

```
normalize(v1): Vec {x: 0.2672612419124244, y: 0.5345224838248488, z: 0.8017837257372732}
|normalize(v1)|: 1
```

## 22.12 矩阵与向量相乘

```matnn
Console.log("\n--- 矩阵与向量相乘 ---");
var resultVec = Mat.mulVec(m1, v1);

```

**输出结果**：

```

```

## 22.14 本章小结

本章介绍了 Matnn 的 3D 数学功能：

- **Vec 向量**：
  - `new Vec(x, y, z)` 创建向量
  - `Vec.add(v1, v2)` 向量加法
  - `Vec.sub(v1, v2)` 向量减法
  - `Vec.mul(v, scalar)` 标量乘法
  - `Vec.dot(v1, v2)` 点积
  - `Vec.cross(v1, v2)` 叉积
  - `Vec.length(v)` 向量长度
  - `Vec.normalize(v)` 向量归一化

- **Mat 矩阵**：
  - `new Mat()` 创建矩阵
  - `Mat.mulVec(m, v)` 矩阵与向量相乘
  - `Mat.mul(m1, m2)` 矩阵与矩阵相乘
