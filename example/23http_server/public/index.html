天然异步

所有 IO 操作默认异步执行，通过 TaskHandler 统一管理任务生命周期。

🔀

串行 / 并行

支持任务并行执行，需要串行时使用 Task.wait() 即可阻塞等待。

🌐

内置 HTTP 服务

原生支持 HTTP 客户端与服务端，静态文件托管、路由注册开箱即用。

代码示例

// 创建 HTTP 服务器
var server = HttpServer.new();
server.static("/public", "./public");
server.start(8080, "127.0.0.1");

// 等待启动完成
Task.wait(server.start(8080));
